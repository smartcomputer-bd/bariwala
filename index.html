☁️ Firebase Cloud Sync

একই Firebase অ্যাকাউন্ট দিয়ে অন্য ডিভাইসে যুক্ত হলে ভাড়াটিয়া, ইউনিট, বিল, জমা ও সেটিংস সিংক হবে।

Firebase সিংক সংযোগ করা হয়নি।

নোট: এটি সফটওয়্যারের Admin লগইন থেকে আলাদা। Firebase Console → Authentication থেকে ইমেইল/পাসওয়ার্ড ব্যবহারকারী তৈরি করতে হবে।

☁️ সিংক নির্দেশনা

  1. Firebase Console-এ Email/Password sign-in চালু করুন।
  2. Authentication → Users থেকে সিংক করার জন্য একটি অ্যাকাউন্ট তৈরি করুন।
  3. Firestore Rules-এ কেবল লগইন করা ব্যবহারকারীকে নিজের UID-এর ডেটায় প্রবেশাধিকার দিন।
  4. সব ডিভাইসে একই Firebase অ্যাকাউন্ট ব্যবহার করুন।

প্রথমবার সংযোগে Firebase-এ আগে ডেটা থাকলে সেটি স্থানীয় ডেটার জায়গা নেবে। Firebase খালি থাকলে বর্তমান ডেটা প্রথমবার আপলোড হবে। সংযোগের আগে JSON Backup নেওয়া নিরাপদ।
